ghv · GitHub Release 下载代理

把 github.com 换成当前域名即可代理下载；也可以在下面输入仓库名浏览 README 和 Release。

示例： jpillora/chisel cli/cli BurntSushi/ripgrep

转换后的链接会显示在这里…
直连用法（替换域名即可）：
https://github.com/a/b/releases/download/v1.0/f.zip
→ /a/b/releases/download/v1.0/f.zip

也支持 archive 包：/owner/repo/archive/refs/heads/main.zip
或显式接口：/api/proxy?url=...、/api/repo?repo=owner/repo
